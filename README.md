# CreditPathAI

**CreditPathAI** is a machine learning-driven platform designed to predict borrower default risk and optimize the loan recovery lifecycle. The system leverages diverse datasets to recommend personalized recovery actions, improve delinquency recovery efficiency, and equip collection agents with actionable insights.

---

## Project Objective

- Design and develop a ML platform that predicts borrower default risk.  
- Recommend personalized recovery actions for delinquent loans.  
- Use open-source technologies to ensure cost-effectiveness, scalability, and reliability.  
- Equip collection agents with actionable insights to improve recovery efficiency.

---

## Project Workflow

### 1. Data Ingestion
- Load datasets from sources such as:
  - [Kaggle Loan Default Dataset](https://www.kaggle.com/)
  - Microsoft R Server Loan Credit Risk  
- Tools: CSV/Excel ingestion, SQLite/PostgreSQL, SQL queries.

### 2. Feature Engineering
- Perform cleaning, aggregation, joining, and feature transformation.  
- Create numerical, categorical, and derived features suitable for modeling.  

### 3. Modeling
- Train classification models to predict borrower default risk.  
- Evaluate models using metrics such as Accuracy, F1-score, Precision, Recall, and AUC-ROC.  
- Perform hyperparameter tuning for optimal performance.

### 4. Recovery Recommendation
- Recommend personalized recovery actions based on predicted risk.  
- Integrate with actionable dashboards for collection agents.

### 5. Visualization & Insights
- Visualize distributions, correlations, and feature importance.  
- Provide insights into high-risk borrowers and effective recovery strategies.
